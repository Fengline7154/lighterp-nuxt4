# 系统描述

基于NUXT4开发的轻量级全栈ERP系统,技术栈为NUXT4 + Vue3 + Postgresql + Redis,  
应用场景为10-30人左右的缺乏自动化与数字化生产线小厂,业务逻辑相比专业级ERP较为简单,  
在保证不违反业务核心规则的同时又有较强的灵活性,支持订单在多种状态下的取消操作,
全流程审计,为具体操作追溯与责任判定提供依据,
符合小厂订单需求多变,生产管理混乱,相关记录全靠纸笔与excel的实际情况.


## 一、分层架构
参考了DDD领域驱动设计理念,后端总计分为四层:  
  
API Route (server/api/)  
鉴权 + 参数校验 → 调用 Application/Service  
↓  
Application (server/application/)  
跨服务编排 + 事务管理 + 审计记录  
↓  
Service (server/services/)  
原子业务逻辑 + 事务透传  
↓  
Repository (server/repositories/)  
数据库操作封装 + TxContext  
↓ 
infrastructure(Prisma → PostgreSQL + Redis)  
基础层实现数据库客户端创建

## 二、核心设计原则  
  
### 1. 数值精度  

-使用Prisma的Decimal类型存储所有用于生产计算的数值  
-支持4位小数的精确计算,但是仍建议存储时使用基本单位如mm以避免小数
-在服务层计算时使用自定义的IDecimal类型以获得prisma的精确计算方法  

### 2. 事务管理

- 数据层写操作使用 `tx?: TxContext` 参数以确定唯一事务入口
- 服务层用 `runInTransaction(tx, prisma, fn)` 统一事务入口
- 应用层用 `prisma.$transaction` 编排多个服务调用,从而实现失败回滚
  
### 3. 审计

- 所有写操作在 Application 层记录审计日志
- 审计日志记录变更字段、新旧值、备注等以方便追溯
- 由api自动注入用户id并写入审计日志以支持操作留痕  

### 4. 权限  

-采用原子级别的权限划分,支持用户拥有角模板外的自定义权限
-符合小厂一人多职的实际情况,避免来回切换账号完成不同操作
-业务api均存在原子级别的权限校验,避免了被绕过的可能
-核心业务有群组检查,A部门的经理无法修改B部门下的员工信息  

### 5. Token 管理

- 采用Access Token + Refresh Token + Csrf Token的设计
- 前端中间件：路由跳转时自动刷新过期 token
- 请求时自动注入 Authorization 头，401 自动重试  
  
## 三、业务模块与功能

| 模块名称   |                            模块功能                                 |
| ---------- | ----------------------------------------------------------------- |
| **订单**   | 生产订单状态机,审批流,订单进度,软删除,支持标准品/变型品/定制品订单创建  |
| **库存**   | 初始化,通用出入库,可用量计算,订单关联,库存库位调拨,红冲,盘点,生产领料   |
| **生产**   | 生产报工,进度统计,人工成本显示,批量操作,支持修改历史工单               |
| **采购**   | 采购相关增删改查,采购单搜索                                          |
| **BOM**    | 版本迭代,物料展开,配合订单进行需求计算,变型品自动克隆,支持同步创建新物料|
| **产品**   | 产品相关增删改查, 批量启停                                          |
| **工序**   | 分为标准工序/模板工序/订单工序,支持向下覆盖,工价分配                  |                
| **用户**   | 自定义权限管理,用户启停,密码重置,个人信息修改                        |
| **员工**   | 员工相关增删改查,支持批量创建                                       |
| **客户**   | 功能同上,不支持批量                                                |
| **供应商** | 功能同上,无批量操作                                                |
| **库位**   | 产品查找,库位分类                                                  |
| **审计**   | 全系统的操作追溯,支持按时间搜索                                     |
| **报表**   | 缺料分析,生产记录,库存类别占比,订单完成进度,低库存预警                |
